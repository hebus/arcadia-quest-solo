# Checklist de validation manuelle (tablette)

À faire sur l'appareil réel, en paysage.

- [ ] L'application s'affiche en paysage sans défilement horizontal.
- [ ] Toutes les zones tactiles se touchent sans erreur (≥ 44 px).
- [ ] Le texte reste lisible à distance de jeu (~1 m).
- [ ] Utilisation à une main possible pour : activer un héros, confirmer une action, lancer le Monster Turn.
- [ ] Fermer l'onglet en pleine manche puis rouvrir : « Reprendre » restaure la partie sans perte.
- [ ] Mode avion après installation : l'application se charge et la partie reste jouable.
- [ ] Changer d'application puis revenir : l'état est intact.
- [ ] Corriger une erreur de saisie (position, blessure) via Corrections puis Annuler.
- [ ] Partie longue (plusieurs manches) : aucune lenteur, journal cohérent.
- [ ] Exporter puis importer sur un autre appareil : la partie est identique.
- [ ] Navigation au clavier : Tab parcourt les boutons dans l'ordre, le focus est visible.
- [ ] Comparer 3 Monster Turns complets avec une résolution manuelle du livret : mêmes monstres, cibles et déplacements. Noter tout écart dans `docs/rules/open-questions.md`.
- [ ] Faces des dés réglées d'après les dés physiques.
